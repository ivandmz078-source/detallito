# Música ambiental

Para habilitar la música, agrega aquí una pista instrumental que tengas autorización para usar en una página pública. Una opción ideal es un MP3 de piano ambiental cálido, sin voces y con volumen uniforme.

Después abre `script.js` y cambia la constante `playlist` siguiendo el ejemplo incluido allí. Usa exactamente el nombre del archivo que agregaste.

La página no configura ninguna pista por defecto para no prometer música ni enlazar obras sin permiso. Cuando agregues una pista válida, la pantalla de entrada mostrará «Entrar con música», intentará reproducirla al tocar ese botón, se repetirá y aparecerán los controles discretos de pausa y silencio al 16 % de volumen.
