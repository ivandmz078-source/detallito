# Detallito para Yamileth

Una página estática romántica lista para GitHub Pages. No necesita dependencias ni instalación.

## Archivos

- `index.html`: estructura y contenido editable.
- `styles.css`: paleta, disposición responsiva y animaciones.
- `script.js`: interacción, capítulos, luces y la lógica de audio.
- `poems.js`: 100 sonetos completos, uno por pantalla, con navegación, favoritos y fuente.
- `assets/audio/`: coloca aquí una pista instrumental autorizada; consulta su README.

## Personalización rápida

1. Abre `index.html` y escribe tu carta en el bloque que dice «Escribe aquí tu carta…».
2. Si cuentas con una pista autorizada, agrégala en `assets/audio/` y sigue las instrucciones de `assets/audio/README.md`.
3. Abre `index.html` en un navegador para revisarla.

## Publicar en GitHub Pages

1. Sube estos archivos a la rama `main` del repositorio `detallito`.
2. En GitHub ve a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`.
4. Guarda. GitHub mostrará la URL pública cuando termine de publicar.

La página usa rutas relativas, por lo que funciona también bajo la subruta de un repositorio de GitHub Pages.

## Colección poética

La experiencia incluye los sonetos I–C de William Shakespeare en inglés original. El texto proviene de **Shakespeare's Sonnets**, Project Gutenberg eBook #1041, fuente que lo identifica como dominio público en Estados Unidos. No se incluyen traducciones modernas para no atribuir ni reutilizar una traducción con derechos sin verificar.
