# Detallito para Yamileth

Un regalo digital romántico e interactivo listo para GitHub Pages. No necesita dependencias ni música externa.

## Archivos

- `index.html`: estructura y contenido editable.
- `styles.css`: paleta, disposición responsiva y animaciones.
- `data.js`: los doce mensajes, diez mensajes principales, diez sorpresas, la carta y las cien expresiones de amor.
- `script.js`: navegación, corazones SVG trazados, animaciones y la escena final.

## Personalización rápida

1. Abre `index.html` y escribe tu carta en el bloque que dice «Escribe aquí tu carta…».
2. Para editar el contenido, modifica `data.js`; todos los textos personales están organizados por sección.
3. Abre `index.html` en un navegador para revisarla.

## Publicar en GitHub Pages

1. Sube estos archivos a la rama `main` del repositorio `detallito`.
2. En GitHub ve a **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**, rama `main` y carpeta `/(root)`.
4. Guarda. GitHub mostrará la URL pública cuando termine de publicar.

La página usa rutas relativas, por lo que funciona también bajo la subruta de un repositorio de GitHub Pages.
